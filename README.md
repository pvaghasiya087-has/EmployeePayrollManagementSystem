# Employee Payroll Management System (VB.NET)

A **complete payroll management system** built with **VB.NET and SQL Server**, designed for small to medium-sized companies to manage employee salaries, payroll, and reports efficiently.

## Features

- **Employee Management**: Add, edit, and delete employee records.
- **Payroll Management**: Generate payrolls with allowances, tax, and net salary calculation.
- **Reports**: Filter and view payroll reports by employee, month, and year.
- **Payslip Preview**: Print and view individual payslips.
- **Export to Excel**: Export payroll and reports for easy sharing.
- **User Authentication**: Login system with roles (Admin/HR/Employee).
- **Professional UI**: Dashboard, navigation menu, and panels for a modern look.
- **Input Validation**: Ensures all data is accurate and secure.

## Technologies Used

- **VB.NET** (Windows Forms)
- **SQL Server LocalDB**
- **Microsoft Office Interop Excel** (for exports)
- **ADO.NET** for database access
